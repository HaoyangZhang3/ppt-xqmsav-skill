# 提示词句式模板与词库（变形转场视频）

## 一、单段转场句式模板

```
[镜头/主体] + [方向性动作] + [形状变形过程] + [落点化为下一场景元素] + [镜头后续运动]
```

示例（莲花碗 → 张拉膜）：

> 镜头向右下方的白色莲花碗极速坠落，莲花碗的白色花瓣一片片向上翻卷、合拢，镜头冲入碗心，翻转的白色花瓣在空中重新排列，变成红色四角张拉膜上的白色交叉骨架，红色地面翻上膜面。

要点：
- 一段只写 1~2 个变形动作，动作之间用"紧接着/随后"衔接。
- 变形必须落在两个场景的"相似元素"上（白花瓣→白骨架：同为白色放射状结构）。
- 写清颜色归属（红色/白色/黑色各自转移到哪个元素），统一配色全靠颜色词约束。

## 二、变形动词库

| 类别 | 动词 |
|---|---|
| 化形 | 化为、变成、重新排列、落点化为、退向、延展为、汇聚成 |
| 翻转 | 翻卷、合拢、展开、闭合、弯曲、翻上、升起、亮起 |
| 流动 | 倾泻、漫开、铺满、漫过 |
| 飞行 | 飞入、冲入、坠落、俯冲、穿过、拉出、拉升至、越过、摇起 |

## 三、镜头运动词库

飞入 → 俯冲穿过 → 极速坠落 → 冲入（主体内部）→ 翻转 → 垂直俯拍 → 贴水面拉出 → 越过桥面 → 向上摇起（回环）

原则：每段给镜头一个明确的进入方式和一个明确的离开方式，"离开方式"即下一段的"进入方式"。

## 四、长链条长提示词写法（多图引用式）

当模型支持 @图片N 引用时，把整条链写进一条提示词：开头点明起始场景与入场，随后按顺序逐段"场景→动作→落点"，结尾回到 @图片1 形成闭环。每段之间用"紧接着"串联。

杭州案例完整提示词原文（效果见 assets/case-hangzhou/）：

> 红色飞鸟群向右飞入红色天空，落点化为成片的红色楼群，左侧白色波浪形场馆与右侧白色莲花碗体育场随之展开。紧接着镜头从杭州之门的 U 形拱洞中央俯冲穿过，向右下方的白色莲花碗极速坠落，莲花碗的白色花瓣一片片向上翻卷、合拢，镜头冲入碗心，翻转的白色花瓣在空中重新排列，变成红色四角张拉膜上的白色交叉骨架，红色地面翻上膜面，镜头拉升至垂直俯拍，城市的黑色道路与阴影延展为黑色水面，红色道路上的白色标线汇聚成斜向贯穿画面的白色栈道，城市楼群的黑色剪影退向栈道两端，化为两岸的黑色树林。最后镜头沿白色栈道俯冲着向前飞行，从正中央一座红色膜棚的中心垂直穿过，膜面的红色在穿透瞬间向下倾泻、漫开，铺满整个画面下方，变回桥下的红色水面，镜头入水后向前穿出，头顶栈道的白色板条一根根闭合、弯曲，连成拱桥的白色拱洞，黑色桥身从水面升起，镜头贴着水面极速向后拉出，完整的黑色拱桥与红色倒影重现，随即镜头越过桥面向上摇起，黑色林带横亘画面，红色雷峰塔在林梢中央重新亮起，回到最初的画面。

## 五、分段接力生成法（首尾帧式，推荐）

1. 场景链 A→B→C→D→A 拆成 A→B、B→C、C→D、D→A 四段。
2. 每段：首帧 = 前一场景风格化图，尾帧 = 后一场景风格化图；提示词只写中间变形过程。
3. 若模型支持，直接用图 A 作首帧、图 B 作尾帧；若不支持，先生成上一段，从其最后一帧截图作为下一段首帧。
4. 段与段的衔接处用抽帧脚本检查：变形元素的颜色/位置是否连续，不连续则补一句位置约束重生成。
5. 全部通过后按序拼接。

## 六、常见失败与对策

| 症状 | 原因 | 对策 |
|---|---|---|
| 变形时画面崩坏/元素乱入 | 单段动作过多 | 拆段，每段 ≤2 个变形 |
| 两段之间颜色跳变 | 风格化图配色不统一 | 回到第 2 步重做风格化 |
| 转场生硬像硬切 | 缺少相似元素锚点 | 重选相邻场景或加中间过渡场景 |
| 主体变形方向失控 | 提示词缺方向词 | 每个动作都加"向右/向上/垂直"等方向 |
| 结尾没回到起点 | 链路未闭环 | 场景链设计时首尾必须是同一场景 |
